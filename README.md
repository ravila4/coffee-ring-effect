# coffee-rings — evaporation-driven particle deposition

Procedural coffee stains generated by simulating the actual coffee-ring
physics (Deegan et al.), rendered once to a canvas and reusable as a static
image. Zero dependencies, ~40 ms per stain, seed-reproducible.

## The physics

A drying drop's contact line pins to the surface. Evaporation flux diverges at
the thin edge, so an outward capillary flow feeds the rim, carrying suspended
particles that jam there — that's the dark ring. We integrate Deegan's
closed-form depth-averaged velocity field directly; no fluid solver needed.

```text
        evaporation (strongest at edge)
      ↑   ↑    ↑     ↑      ↑↑↑
    ┌─────────────────────────┐
    │   →    →     →    →→→ ██│  ← particles advected outward,
    └─────────────────────────┘     jam at the pinned contact line
    center              contact line

  v(ρ,t) = [(1−ρ²)^(−λ) − (1−ρ²)] / (4ρ(1−t)),  λ = 1/2
```

- **Ring**: particles reaching the pinned line deposit with a short inward
  tail (jamming width) — sharp outer edge, darkest at the rim.
- **Secondary rings**: stick-slip events depin the contact line and pull it
  inward; deposition resumes at the new radius → nested rings.
- **Interior mottle**: whatever is still suspended at dry-out settles in
  place as soft residue.
- **Irregular outline**: the contact line is a closed noisy contour — 2D
  simplex fBm sampled along a circle in noise space (seamless by construction).
- **Satellites**: smaller drops scattered along a splash direction run the
  same simulation.

## Layout

| Path | What | Tested |
|---|---|---|
| `src/rng.js` | mulberry32 + gaussian/uniform samplers | yes |
| `src/noise.js` | 2D simplex noise + fBm | yes |
| `src/contour.js` | noisy closed contact line | yes |
| `src/physics.js` | velocity field, advection–diffusion–deposition, stick-slip | yes |
| `src/render.js` | deposits → splats/washes → canvas (multiply blending) | visual |
| `demo/index.html` | 3×3 grid, click to re-brew | — |

## Usage

```bash
node --test                      # run the suite
python3 -m http.server 8000      # then open http://localhost:8000/demo/
```

```js
import { generateStainCanvas } from './src/render.js';
const canvas = generateStainCanvas({ size: 560, seed: 42 });
el.style.backgroundImage = `url(${canvas.toDataURL()})`;
```

Render once, reuse as an image — generation cost is paid exactly once per
seed. See `docs/research-notes.md` for the research this design came from
(including why live SVG `feTurbulence` filters were rejected).
